# 附录 A · 报错处理万能模板

下次报错，把这段话 + 报错原文一起发。**红字全部选中复制**，不要只截一句——关键信息经常在中间几行。

```
我遇到报错了。请按这个顺序处理：

先用一句大白话告诉我：这个错误大概率是什么意思
只给我一个最可能有效的解决办法，不要一次给我五个方案
能自己修的直接修，需要我操作的告诉我点哪里
修完重新跑一遍刚才失败的命令
最后告诉我：现在能不能继续下一步

报错原文如下：
（把窗口里的红字全部选中复制，粘贴在这里）
```

技巧：如果它修了两次还是同样的错，说一句 **「换个思路，不要再用刚才那个方法」**。
