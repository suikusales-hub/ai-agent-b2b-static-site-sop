# 第 6 步 · 一次写 5 个页面

语料准备好（或文件拖完）后发这段。把 `[...]` 换成你填好的清单。

```
现在一次把 5 个页面写出来：首页、关于我们、联系我们、隐私政策、服务条款。
语料在下面（以及我刚拖给你的文件里）：
[把上面整理出来的清单，或者填好的表，粘贴在这里]
各页面要求：
【首页】

Hero：一句话说清"我们是谁 + 为谁做什么"，不要空话
核心产品分类：3-6 个卡片，链到后面的分类页（先做成占位链接）
为什么选我们：4 条，每条必须是我语料里真实存在的事实，带数字最好
认证与质检：列出真实认证
合作流程：4 步（询盘 → 报价 → 打样 → 量产）
FAQ：3-5 条，直接用我给的"客户最常问的问题"
底部询盘 CTA

【关于我们】
公司简介 → 工厂与产能（带数字）→ 团队 → 质量控制 → 认证 → CTA
【联系我们】
邮箱 / WhatsApp / 电话 / 地址 → 询盘表单 → 响应时效承诺（比如"12 小时内回复"）
【隐私政策】路径 /privacy/
说明：收集哪些信息、用途、存储在哪、是否用 Cookie、客户如何要求删除、联系邮箱。
按 GDPR 的通用结构写，但内容必须对应我上面给的真实情况。
【服务条款】路径 /terms/
写：报价说明、MOQ、付款方式、交期、质保、知识产权、争议解决。
标题用 "Terms of Sale"，比 "Terms and Conditions" 更贴合 B2B。
铁律：

我语料里没有的数字、认证、客户名，一律不许编。用 [待补充：xxx] 占位，
最后汇总告诉我一共缺哪些。
英文要像人写的。禁止出现 "professional manufacturer with rich experience"、
"high quality and competitive price" 这类模板句。
隐私政策和服务条款顶部各加一行 HTML 注释，提醒我这是初稿、需要专业人士复核。
隐私政策和服务条款只放页脚，不要放进主导航。
每个页面写完后，告诉我这个页面的主关键词是什么。

做完后给我：5 个页面的文件路径 + 缺失信息清单。
```
